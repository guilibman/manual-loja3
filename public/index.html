Millenium — ERP › Pendência Total

Como dar Pendência Total em um pedido

⚙️ Millenium 📋 Lista Pré-Faturamento

A Pendência Total é usada quando a loja não tem nenhuma peça do pedido disponível para envio. Ao executar esse processo, o sistema registra a indisponibilidade e realoca o pedido para outro seller ou aciona o cancelamento, dependendo da situação.

🚨
Atenção — Seller 101 (Benfica/CD): O seller 101 nunca deve usar Pendência Total diretamente. Isso cancela o pedido definitivamente na VTEX e reembolsa o cliente automaticamente, mesmo que outra loja possa atendê-lo. Nesse caso, comunique ao time de e-commerce para tomar a ação correta.
1
Abra a Lista Pré-Faturamentos de Saída

No Millenium, acesse a aba Lista Pré-Faturamentos de Saída. Localize o pedido que precisa de pendência total na lista.

Lista Pré-Faturamentos de Saída — clique para ampliar
2
Selecione o pedido e acesse Ações › Pendência Total

Marque o checkbox do pedido na lista. Em seguida, clique no botão Ações (na barra inferior) e selecione Pendência Total no menu que aparece.

Botão Ações › Pendência Total — clique para ampliar
3
Confirme clicando em Executar

Uma janela de confirmação será aberta mostrando o número do pré-faturamento. Verifique se é o pedido correto e clique em Executar para confirmar a pendência.

Tela de confirmação — clique Executar para finalizar
ℹ️
O que acontece depois: O sistema registra a indisponibilidade. O pedido sai da sua fila e o Millenium busca outro seller para atendê-lo. Acompanhe na Lista de Pedido de Venda se o pedido foi realocado.
Millenium — ERP › Correção de Etiqueta de Transporte

Como corrigir erro na Etiqueta de Transporte

⚙️ Millenium 📦 Embarques 📮 Correios

Quando a etiqueta de transporte não é gerada automaticamente, o motivo aparece no Log de Erros API Correios do Millenium. O erro mais comum é um CEP incorreto ou inexistente no cadastro do cliente.

1
Acesse o Log de Erros API Correios

No Millenium, abra a tela Log de erros com a api Correios (PPN). Busque pelo número da nota do pedido com problema.

Log de Erros API Correios — clique para ampliar
2
Identifique o erro pelo número da nota

A coluna Mensagem mostra o erro exato — geralmente "CEP-003: O CEP XXXXXXXX não foi encontrado". Anote o CEP com problema.

Mensagem de erro indicando o CEP incorreto — clique para ampliar
3
Acesse o pedido e clique em Alterar Cliente

Na Lista de Pedido de Venda, abra o pedido com erro. Clique no link Cliente e selecione Alterar Cliente.

Clique em Cliente › Alterar Cliente — clique para ampliar
4
Corrija o CEP na aba Geral e salve

Na tela Alterar Cliente, vá até a aba Geral e localize o endereço com o CEP incorreto. Um cliente pode ter vários endereços — verifique todos. Corrija o CEP e clique em Salvar.

Aba Geral › campo CEP — corrija e clique em Salvar
5
Gere a etiqueta novamente e valide

Com o CEP corrigido, volte à tela de embarques e tente gerar a etiqueta. Se o processo foi concluído corretamente, a etiqueta será emitida normalmente. Caso o erro persista, verifique se há outros endereços com CEP inválido no cadastro.

⚠️
Atenção: Um mesmo cliente pode ter múltiplos endereços cadastrados. Se o erro continuar após corrigir o primeiro CEP, verifique os demais — pode haver outro inválido gerando conflito.
ℹ️
Dica: Para confirmar o CEP correto antes de editar, consulte o endereço do pedido diretamente na VTEX — ele mostra o endereço informado pela cliente no momento da compra.
Millenium — ERP › Realocar Pedido

Como realocar (copiar) um pedido

⚙️ Millenium 📋 Pedido de Venda

Use este processo quando um pedido já faturado precisa ser reenviado ou redirecionado. Situações comuns: extravio na transportadora, item com defeito encontrado no empacotamento, ou necessidade de realocar para outra filial.

Vídeo tutorial — Como realocar (copiar) um pedido no Millenium
1
Localize o pedido e acesse Ações › Copiar Pedido

Na Lista de Pedido de Venda, localize o pedido a ser copiado. Clique em Ações › Copiar Pedido.

2
Confirme manter dados de frete e itens

O sistema perguntará se deseja manter os dados de frete → Sim. Em seguida, se deseja manter os mesmos itens → Sim. Se necessário, remova itens que não precisam ser reenviados.

3
Defina a filial de destino

Se o pedido vai para a mesma filial, não altere nada. Se vai para uma nova filial, atualize os seguintes campos:

  • Filial — ex.: Ipanema = código 45
  • Conta — ex.: Caixa E-Commerce Ipanema
  • Transportadora e valor do frete
4
Marque para nascer aprovado e efetive

Marque a opção para o pedido nascer já aprovado. Clique em Efetivar → confirme na tela seguinte → clique em Próximo Passo → Efetivar novamente.

5
Anote o número do novo pedido e repasse à filial

O sistema gerará um novo número de pedido. Anote esse número e repasse para a filial responsável faturar o quanto antes.

⚠️
Mudança de estado (RJ → SP): Se a filial de destino for de um estado diferente da origem, além de alterar a filial e conta, é necessário ajustar a modalidade de frete — pois incidem outros encargos e impostos. Em caso de dúvida, acione o time de e-commerce.
ℹ️
Atenção: Verifique se o pedido original foi devidamente encerrado após a cópia para evitar duplicidade no sistema.
Millenium — ERP › Entrada de Produto

Como dar Entrada de Produto (estoque manual)

⚙️ Millenium 📦 Logística 🔢 Estoque

A Entrada de Produto é o processo manual de adição de estoque a um produto em uma filial específica no Millenium. Deve ser usado com cuidado — se feito incorretamente, pode gerar pendência na loja.

ℹ️
Quando usar: O caso mais comum é quando um pedido fica travado no status "Pronto para Manuseio" na VTEX — o que indica que o pedido não foi integrado ao Millenium por falta de estoque no seller designado. Para destravar, inserimos um estoque fake no produto para forçar a integração. Depois, o seller dá pendência manual para o sistema realocar o pedido para outra filial com estoque real.
🚨
Atenção: Analise cuidadosamente antes de executar. Esse processo altera o estoque real da filial no sistema. Após efetivar, confirme na Consulta de Estoque se a quantidade foi adicionada corretamente no produto e SKU desejados.
1
Acesse Logística › Recebimento › Movimentações › Entrada de Produto

No Millenium, navegue até Logística › Recebimento › Movimentações e abra a tela Entrada de Produto.

2
Selecione a filial e insira o código do produto

No campo Filial, selecione a loja que receberá o estoque. Em seguida, insira o código do produto no campo correspondente.

Tela Entrada de Produto — filial, código e quantidade — clique para ampliar
3
Selecione o SKU (tamanho) e a quantidade

Uma janela de Grade abrirá mostrando os SKUs disponíveis (tamanhos e cores). Insira a quantidade desejada na célula correspondente ao SKU correto. Clique em F12 OK para confirmar.

Grade do produto — selecione o SKU e insira a quantidade — clique para ampliar
4
Clique em Efetivar

Com a quantidade preenchida, clique em (F12) Efetivar na barra inferior para confirmar a entrada de estoque.

5
Confirme na Consulta de Estoque

Após efetivar, acesse a Consulta de Estoque no Millenium e verifique se a quantidade foi adicionada corretamente no produto e SKU desejados. Essa confirmação é obrigatória antes de qualquer passo seguinte.

⚠️
Próximo passo após o estoque fake: Avise ao seller da filial que recebeu o estoque para que ele dê pendência manual no item assim que receber na fila. Isso fará o sistema realocar o pedido para outra filial com estoque real.
